DNS

DNS (Domain Name System) significa Sistema de Nombres de Dominio.

HOSTING DNS CICLO DE VIDA DE LOS SITIOS WEB PROTOCOLOS DE COMUNICACIÓN

¿QUÉ ES?

El sistema de nombres de dominio (DNS) es el componente del protocolo estándar de Internet responsable de convertir los nombres de dominio fáciles de usar en las direcciones de protocolo de Internet (IP) que emplean las computadoras para identificarse entre sí en la red.

¿CÓMO FUNCIONA?

Cuando un usuario escribe una dirección web en el navegador:

  • El navegador solicita la dirección IP asociada al dominio.
  • La consulta llega a un servidor DNS.
  • El servidor DNS busca la información correspondiente.
  • Se obtiene la dirección IP del servidor.
  • El navegador se conecta con ese servidor y solicita la página web.


    • PRINCIPALES TIPOS DE REGISTROS DNS

  • A: relaciona un dominio con una dirección IPv4.
  • AAAA: relaciona un dominio con una dirección IPv6.
  • CNAME: crea un alias para otro dominio.
  • MX: indica los servidores encargados del correo electrónico.
  • NS: especifica los servidores DNS responsables del dominio.
  • TXT: permite almacenar información de texto, utilizada entre otras cosas para verificaciones y seguridad.
