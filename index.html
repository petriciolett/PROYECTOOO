TIPOS DE HOSTING

El hosting, también llamado alojamiento web, es un servicio que permite almacenar los archivos de un sitio web en un servidor para que puedan ser consultados a través de Internet.

PRINCIPALES TIPOS DE HOSTING

Hosting compartido

Varios sitios web utilizan los recursos de un mismo servidor. Es económico y adecuado para páginas pequeñas.


Hosting VPS

Un servidor físico se divide en varios servidores virtuales. Ofrece más recursos y control que el hosting compartido.


Hosting dedicado

Un servidor completo está destinado a un solo cliente. Tiene mayor rendimiento y control, aunque suele ser más caro.


Hosting en la nube (Cloud Hosting)

Utiliza recursos de varios servidores conectados. Puede adaptarse a aumentos de tráfico y ofrece buena disponibilidad.


Hosting administrado

El proveedor se encarga de tareas técnicas como actualizaciones, seguridad y mantenimiento.


Reseller Hosting

Permite contratar recursos de alojamiento para posteriormente ofrecer servicios de hosting a otros usuarios.

¿PARA QUÉ SIRVE?

El hosting permite que los archivos HTML, CSS, JavaScript, imágenes y otros recursos de una página web estén disponibles en Internet. Para acceder a ellos normalmente se utiliza un nombre de dominio.
